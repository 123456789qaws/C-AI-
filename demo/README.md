# Luna-for-C Demo

纯前端演示版本，展示 Luna-for-C 核心 UX 体验。

## 快速开始

### 方式一：直接打开文件
1. 双击 `index.html` 文件（或在浏览器中打开）
2. 等待 Monaco Editor 加载完成
3. 开始体验

### 方式二：使用本地服务器
```bash
# 使用 Python
python -m http.server 3001

# 或使用 Node.js
npx serve demo -l 3001

# 或使用 pnpm
pnpm dlx serve demo -l 3001
```

然后访问 http://localhost:3001

## 功能特性

### 1. 三栏布局
- **左侧**：检查点列表、任务信息、引导问题
- **中心**：Monaco Editor 代码编辑器（C 语言）
- **右侧**：Luna AI 聊天面板

### 2. 检查点系统
- **cp1**：AI Socratic 对话 - 递归终止条件
- **cp2**：测试通过 - 隐藏测试用例

### 3. 代码锁定机制
- 未通过检查点的代码区域会被锁定
- 锁定区域显示灰色背景和锁图标
- 尝试编辑会自动回滚并显示提示

### 4. AI 对话引导
- Luna 只提问，不直接给出完整代码
- 根据用户回答动态调整问题
- 智能检测代码中的关键元素

### 5. 模拟验证
- 正则表达式检查代码模式
- 关键词匹配判断回答质量
- 模拟测试执行验证代码正确性

### 6. 教师视角
- 切换到教师视角可查看所有内容
- 显示隐藏测试用例
- 代码区域全部解锁

## 交互流程

1. **开始任务**
   - 查看左侧检查点列表
   - 阅读引导问题和通过规则

2. **编写代码**
   - 在 Monaco Editor 中编写 C 代码
   - 注意锁定区域（第 12-20 行、22-40 行）

3. **与 Luna 对话**
   - 在右侧聊天面板输入回答
   - 按 Enter 发送消息
   - Luna 会引导你思考递归终止条件

4. **请求验证**
   - 点击"请求验证"按钮
   - 系统会自动检查你的代码和回答
   - 通过后自动解锁下一区域

5. **完成任务**
   - 通过所有检查点后
   - "提交作业"按钮会启用
   - 点击提交完成任务

## 技术栈

- **Monaco Editor**：代码编辑器（CDN）
- **Tailwind CSS**：样式框架（CDN）
- **原生 JavaScript**：核心逻辑
- **Mock Data**：模拟后端数据

## 模拟数据说明

### 检查点定义
```json
{
  "id": "cp1",
  "title": "递归终止条件",
  "type": "ai_socratic",
  "gates": [
    { "type": "regex", "rule": "n\\s*<=\\s*1" },
    { "type": "ai_socratic", "rubric": "含 n<=1 且不含完整 fib" }
  ]
}
```

### AI 回复规则
- 代码缺少 `n<=1` → 引导思考终止条件
- 代码包含 `n<=1` → 解锁下一区域
- 请求完整代码 → 拒绝并引导思考
- 包含段错误模式 → 提示调试方法

### 测试执行
- 模拟 Fibonacci 计算逻辑
- 检查代码模式而非真实编译
- 根据代码结构推断执行结果

## 注意事项

1. **无后端依赖**：所有逻辑在前端完成
2. **无网络请求**：数据从 mockData.js 加载
3. **无构建步骤**：直接打开即可使用
4. **响应式设计**：支持不同屏幕尺寸

## 开发说明

如需修改或扩展：

1. **添加新检查点**：编辑 `mockData.js` 中的 `checkpoints` 数组
2. **修改 AI 回复**：编辑 `mockData.js` 中的 `aiSocraticReplies`
3. **调整样式**：编辑 `style.css` 中的 CSS 变量
4. **添加新任务**：在 `tasks/` 目录下创建新的 JSON 文件
